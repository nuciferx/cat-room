# 0001 — ใช้ stack และสายปั้นสัตว์สี่ขาของโป่งไพร

สถานะ : ตกลง 2026-10-24 (เจ้าของงานสั่ง "ใช้สแตกและวิธีการปั้นงาน 3D จากโป่งไพร" · "ทำตามกฎของโป่งไพรทั้งหมด")

## เรื่อง

เกมเลี้ยงแมวต้องมีแมว 3D ที่มีกระดูกและท่าหลายท่า ตรงภาพอ้างอิง 8 ทิศ

## ตัดสิน

- เว็บ three.js + TypeScript + Vite รุ่นเดียวกับ pp3
- ปั้นแมวด้วยสาย `build_quad_meshy.py` ของ pp3 (เมชเดียว → โครงกระดูกสี่ขา `beasts_rig.SKELETON` → ท่าจากไฟล์ค่า) · ต้นทางโมเดลเลือกระหว่าง Meshy (หลัก) กับ Hunyuan3D ในเครื่อง (สำรอง/ทดลอง)
- คัดลอกสคริปต์มาไว้ในโปรเจกต์นี้ ไม่แก้ pp3

## เหตุผล

- สายนี้ทำหมูป่าและหมาสำเร็จแล้ว (pp3 2026-10-11) · ไม่ต้องคิดระบบกระดูก/น้ำหนัก/ท่าใหม่
- รุ่นเดียวกันทำให้ยกห้องโชว์ input map แผงจูน มาใช้ได้ตรง

## ผลที่ตามมา

- ต้องรักษาสำเนาสคริปต์เอง ถ้า pp3 แก้บั๊กในสายนี้ ต้องคัดลอกตามเอง (จด commit ต้นทางใน `docs/ASSETS.md`)
- ท่าแมวเฉพาะ (ขดนอน เลียขน นวด) ต้องเขียนเพิ่ม ชุดท่าหมาไม่ครอบคลุม
