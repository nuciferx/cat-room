## ปัญหาของภาพชุดนี้ (ต้องแก้ก่อนปั้น)

1. **ท่าไม่ตรงกันทุกมุม** — แต่ละช่องแมวก้าวขาไม่เหมือนกัน (S ยกขาหน้า · W ขาหน้าก้าวยาว · N ยกขาหลัง) · Hunyuan 2mv ต้องการ "วัตถุชิ้นเดียวกันมองจากหลายมุม" ถ้าขาอยู่คนละที่ในแต่ละภาพ ขาจะออกมาเป็นก้อนเละ · Meshy ภาพเดียวก็จะได้ท่าก้าวขาติดมา ทำท่ายืนพักยาก → **ต้องได้ท่ายืนนิ่ง ขาทั้งสี่วางพื้นตรง ๆ แยกกันชัด หางตั้ง ปากปิด**
2. **ภาพเล็กไป** — ช่องละ ~418 px หน้าแมวกว้างแค่ ~120 px ตา ~20 px · บทเรียนโป่งไพร : "ภาพชีตรวมใช้ดูรายละเอียดเท่านั้น ภาพเดี่ยว 1024 ได้ทรงดีกว่า" → **สั่งภาพเดี่ยวมุมละ 1024 + ภาพหน้าตรงใกล้ ๆ (`face.png`)**
3. **ตัวอักษร S SW W … อยู่ใต้ตัวแมว** — ติดเข้าโมเดลเป็นเศษ (บทเรียน : "ป้ายชี้/พื้นติดมา = เศษในโมเดล") · ตัดกรอบเหนือตัวอักษรได้ แต่ภาพใหม่ไม่ควรมีป้าย
4. **ทิศซ้าย/ขวาสลับง่าย** — ภาพ W แมวหันซ้ายของรูป = กล้องอยู่ทางขวาของตัวแมว · โป่งไพรเคยพลาดเรื่องนี้ (`left.png` ต้องสลับใน `viewFiles`) → ตรวจทุกครั้งก่อนปั้น
5. ภาพนี้เป็นงานสไตล์ดินปั้นนุ่ม ขนเป็นก้อนใหญ่ → **เป็นข้อดี** ขนแบบนี้ทำเป็นเมชได้เลย ไม่ต้องใช้แผ่นขน (hair card) หรือ shader ขน

## ชีตเดิน 8×8 (ส่งมา 2026-10-24 · `F:/ai3d/in/cat/sprite_sheet_8x8.webp`)

1254×1254 · แถว = 8 ทิศ (S SW W NW N NE E SE) · คอลัมน์ = 8 เฟรมเดิน · ช่องละ ~157 px · ไม่มีตัวอักษร · มีเงาตกพื้น

- **ใช้ปั้นไม่ได้** : ช่องเล็กกว่าภาพ 8 ทิศอีก (157 px) · เฟรมเดียวกันคนละทิศท่าไม่ตรงกัน (เฟรม 0 : S ขานิ่ง · W ก้าวขาหน้า · N ยกเท้าหลัง) · ตัวแมวล้นช่อง (หางแถวล่างโผล่ในช่องบน · E ขาดขอบขวา) ตัดตามตารางตรง ๆ ไม่ได้
- **เฟรมต่อเฟรมขยับน้อยและไม่สม่ำเสมอ** (วัดค่าต่างของพิกเซลเฉลี่ย 3–16 ต่อเฟรม · W เฟรม 7→0 กระโดด 15.6 = วนรอบไม่เนียน) · เป็นภาพ AI ที่ไม่ใช่วงเดินจริง
- **ใช้ได้เป็นแบบอ้างอิงท่าเดิน** : จังหวะยกขา ตัวโยก หางนิ่งตั้ง หัวไม่ส่าย → ใช้ตั้งค่าคลิป `walk` ของแมว 3D
- **ทาง sprite 2D (ไม่ปั้น 3D)** เป็นไปได้แต่ไม่แนะนำ : ได้แค่ท่าเดิน · ทุกท่าอื่น (นั่ง นอน กิน ถูกลูบ) ต้องสั่งชีต 64 ภาพใหม่ และ AI ทำตัวให้เหมือนกันข้ามชีตยาก · 157 px แตกเมื่อกล้องเข้าใกล้ · เกมเลี้ยงสัตว์ต้องการท่าเยอะและกล้องใกล้ → 3D คุ้มกว่า

| | ทาง A : Meshy (ภาพเดียว/หลายภาพ → โมเดลมีสี) | ทาง B : Hunyuan3D ในเครื่อง (4 มุม → ทรง → ฉายสี) |

**แนะนำทาง A เป็นหลัก** เพราะเป็นทางที่พิสูจน์แล้วกับสัตว์สี่ขาและสิทธิ์ชัด · ทาง B ใช้ทดลองคู่กันได้ฟรี และเป็นทางสำรองถ้าเครดิต Meshy หมด · ทั้งสองทางใช้ภาพชุดใหม่ชุดเดียวกัน (`docs/05_gpt_image_brief.md`)

## เครื่องรับไหวไหม

- ฉากเลี้ยงแมว = ห้อง 1 ห้อง + แมว 1 ตัว + ของใช้ไม่กี่ชิ้น · เบากว่าป่าของโป่งไพร (ป่าเตือนที่ ~250k สามเหลี่ยม) หลายเท่า · แมว 8k + ห้อง ~30k สามเหลี่ยม ยังห่างเพดานมาก
- ที่ต้องระวังคือมือถือ : pixel ratio · เงา · post-processing (n8ao) → ใช้ระดับ `q=mid`/`q=low` แบบโป่งไพร
